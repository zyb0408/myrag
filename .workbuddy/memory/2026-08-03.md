## 故障修复：better-sqlite3 ABI 不匹配导致登录 500

- **症状**：启动前后端后登录报 500，server 日志提示 better_sqlite3.node NODE_MODULE_VERSION 127 vs 当前 Node 要求 137。
- **根因**：better-sqlite3 原生模块是 Node 22（ABI 127）编译的，用户终端运行 server 用的是 nvm Node 24.13.0（ABI 137）。
- **修复**：`cd server && PATH="/Users/yingbin/.nvm/versions/node/v24.13.0/bin:$PATH" npm rebuild better-sqlite3`，然后同样用 Node 24 重启前后端。
- **关键约定（重要）**：本机存在多个 Node——managed 22.22.2（/Users/yingbin/.workbuddy/binaries/...，ABI 127）与 nvm 24.13.0（ABI 137）。**启动 server 必须与编译原生模块时使用同一 Node 版本**，建议统一用 `PATH="/Users/yingbin/.nvm/versions/node/v24.13.0/bin:$PATH" npm run dev`。若切换 Node 版本后出现 ABI 报错，重跑 `npm rebuild better-sqlite3` 即可。

### 关键坑（antdv v4 与 React antd 5 差异）
1. **Dropdown 不支持 `:menu="{items}"` 自动渲染**——必须用 `#overlay` 插槽 + `<Menu :items @click>`。否则菜单空白。
2. **Form 必须绑定 `:model` + 子组件 `v-model:value`**——不绑 model 时 antdv v4 校验取不到值（表现为"请输入xx"假报错）。
3. Form 实例方法（resetFields 等）：antdv v4 不用 React 的 `[form]=Form.useForm()`，改用组件 `ref` + `formRef.value?.resetFields()`。
4. menu items 的 icon 需 `h(Icon)` 返回 VNode（非函数）；divider 项需带 key；menu onClick 回调 key 类型为 `string|number`。
5. Select 的 change 回调 value 类型为 `SelectValue`（含 undefined），需 `String(value ?? '')`；value 为 null 时用 `?? undefined`。
6. Table 列 render → `customRender`，操作列用 `#bodyCell` 插槽。
