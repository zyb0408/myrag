# 2026-07-30

## RAGFlow 知识库问答系统 - 初始搭建

完成了基于 RAGFlow 的 Web 知识库问答系统完整搭建：

### 架构
- 三层架构：React 前端 → BFF (Express) → RAGFlow API
- BFF 负责隐藏 API Key、会话持久化 (SQLite)、SSE 透传

### 技术栈
- 前端: React 18 + TypeScript + Vite 6 + Ant Design 5 + Zustand
- 后端: Express + TypeScript + better-sqlite3
- 根目录使用 concurrently 并行启动前后端

### 项目结构
- `client/` - React 前端 (Vite)
- `server/` - BFF 代理层 (Express + SQLite)
- 根 `package.json` 统一管理启动脚本 (`npm run dev`)

### 已实现功能
- 知识库（Chat Assistant）选择
- 对话列表管理（新建/重命名/删除）
- 多轮问答（完整上下文注入）
- SSE 流式输出（打字机效果）
- Markdown 渲染 AI 回复
- 中文 Ant Design 主题

### 配置
- RAGFlow 地址和 API Key 在 `server/.env` 中配置
- 开发时 Vite 自动代理 `/api` 请求到 BFF (3001 端口)

### 关键 API 路由
| 端点 | 说明 |
|------|------|
| GET /api/knowledge-bases | 知识库列表 |
| GET /api/chat-assistants | Chat Assistant 列表 |
| GET/POST /api/conversations | 对话 CRUD |
| GET /api/conversations/:id/messages | 消息历史 |
| POST /api/chat/:convId | 发送消息 (SSE) |

## 多用户隔离改造

完成了完整的多用户认证和对话隔离功能：

### 改造内容
- 新增 `users` 表（id, username, password_hash, display_name, must_reset_password, is_active, is_admin）
- conversations 表新增 `user_id` 列（外键关联 users）
- JWT 认证方案（bcrypt 哈希密码，JWT 7天有效期）
- 系统启动时自动创建种子管理员（admin/admin123，首次登录需重置密码）

### 新增后端文件
- `middleware/auth.ts` — JWT 签发/验证中间件（requireAuth, requireAdmin）
- `routes/auth.ts` — POST /api/auth/login, POST /api/auth/reset-password, GET /api/auth/me
- `routes/admin.ts` — GET/POST/DELETE /api/admin/users, PATCH reset-password

### 新增前端文件
- `stores/authStore.ts` — 登录态管理（token 存 localStorage）
- `pages/LoginPage.tsx` — 登录页面
- `pages/ResetPasswordPage.tsx` — 首次登录重置密码
- `pages/AdminPage.tsx` — 管理员用户管理（表格+增删+重置密码）
- `components/auth/ProtectedRoute.tsx` — 路由守卫（ProtectedRoute + AdminRoute）

### 修改内容
- 所有现有路由的 SQL 查询追加 `AND user_id = ?` 实现数据隔离
- App.tsx 使用 react-router-dom 管理路由
- api.ts 自动附加 Authorization header
- Sidebar 显示用户信息和退出/管理入口

### 技术要点
- SQLite 保留字 `references` 需用双引号包裹
- ESM 下不能使用 require()，改用顶层 import
- 密码用 bcrypt.hashSync 哈希，compareSync 验证
